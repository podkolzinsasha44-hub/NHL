# NHL GM

Реалистичный симулятор генерального менеджера НХЛ для iPhone. Ты — GM одного из 32 клубов сезона 2026-27 с реальными игроками, контрактами и правилами. Цель — Кубок Стэнли.

- Драфт с реальной лотереей, скаутингом и драфт-днём на 7 раундов
- Обмены с умными ИИ-менеджерами
- Переговоры с агентами, свободные агенты, потолок зарплат по CBA 2026-27
- Честный матчевый движок, откалиброванный по статистике НХЛ, без подыгрывания
- Карточки игроков с фото, премиальный «ТВ-трансляционный» дизайн
- PWA под iPhone (портрет), хостинг на Firebase

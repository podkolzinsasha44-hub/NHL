# NHL GM

Реалистичный симулятор генерального менеджера НХЛ для iPhone. Вы — GM одного из 32 клубов сезона 2026-27 с реальными игроками, правилами и календарём. Цель — Кубок Стэнли.

## Что внутри

- **≈1 700 реальных игроков НХЛ** (составы 2026-27, проспекты, свободные агенты) с официальными фото и рейтингами из статистики трёх сезонов и NHL EDGE, плюс вымышленный мировой пул (КХЛ, SHL, Liiga, NL, NCAA) и драфт-классы — до 7 500 игроков.
- **Честный движок матчей**, откалиброванный по сезону 2025-26 (голы, большинство, овертаймы, сейвы, домашнее преимущество). Он не знает, за кого вы играете, и не подыгрывает.
- **Драфт**: реальная лотерея, скаутинг с «туманом войны», big board, драфт-рум, мок-драфты, передрафт.
- **Обмены** с ИИ-менеджерами: стратегии клубов, встречные предложения, удержание зарплаты, NMC/NTC, дедлайн, оценки сделок экспертами.
- **Контракты** по CBA 2026-27: потолок $104M, RFA/UFA, ELC, продления, переговоры с агентами, свободные агенты 1 июля, выкупы, драфт отказов, LTIR.
- Развитие и старение, травмы, мораль, капитан, тренер и тактика, владелец и увольнение, пресс-конференции, лента новостей и соцсетей, награды, игрок месяца, Матч всех звёзд, МЧМ, достижения, альбом карточек, итоги сезона.
- **PWA под iPhone**: портрет, жесты, безопасные зоны, офлайн, установка на экран «Домой».

## Как играть на iPhone

1. Откройте ссылку на игру в **Safari**.
2. Нажмите **«Поделиться»** → **«На экран „Домой“»**.
3. Запускайте игру с иконки — она откроется как приложение, без адресной строки.

Игра сохраняется автоматически в памяти телефона. Для надёжности иногда делайте **экспорт сохранения** (Ещё → Настройки).

## Разработка

```bash
npm install
npm run dev          # локальный сервер
npm test             # тесты движка
npm run calibrate    # проверка реализма на 40 симулированных сезонах
npm run smoke        # прогон нескольких сезонов целиком
npm run build        # сборка в dist/
```

Обновление базы НХЛ (за прокси: `NODE_USE_ENV_PROXY=1`):

```bash
npm run data:fetch   # скачивает данные NHL API в data/raw/
npm run data:build   # пересчитывает public/data/world.json
```

## Выкладка на Firebase Hosting

Проект Firebase: `nhl123-c439b`, адрес игры: **https://nhl123-c439b.web.app**.

1. В Firebase Console: **Hosting and serverless → Hosting → Get started** (прокликать шаги до конца, устанавливать ничего не нужно).
2. **Settings → Project settings → Service accounts → Generate new private key** — скачается JSON-ключ. Никому его не пересылайте и не добавляйте в репозиторий.
3. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**, имя `FIREBASE_SERVICE_ACCOUNT`, значение — всё содержимое JSON-файла.
4. Любой push в `main` (или в ветку разработки) соберёт игру, прогонит тесты и выложит её. Pull request получает превью-ссылку.

Вручную (если установлен Node.js): `npx firebase-tools login`, затем `npm run deploy`.

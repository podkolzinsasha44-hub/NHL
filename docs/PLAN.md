# NHL GM — симулятор генерального менеджера

> Развёрнутый план игры: геймдизайн, логика, данные, дизайн, архитектура, этапы.
> Версия плана: 02.10.2026. Все цифры по НХЛ ниже либо проверены через официальный NHL API в этот день, либо помечены как «ориентир».

---

## Статус реализации (03.10.2026)

**Сделано и играбельно:** этапы M0–M9 и большая часть идей из списка дополнений.

- Данные: ~4 300 реальных хоккеистов на старте (НХЛ и её системы, все 22 клуба КХЛ, Европа, NCAA, юниоры, сборные — §3.1), рейтинги из 3 сезонов статистики и NHL EDGE, реальное расписание на 84 матча, ~100 реальных контрактов звёзд. Остальные зарплаты — модель (условия CapWages запрещают копировать их данные).
- Движок: матч по 20-секундным сегментам, калибровка на 40 сезонах (все 16 метрик в коридорах), плей-офф, травмы, дисквалификации, форма, мораль, тактика, тренерский фактор.
- Менеджмент: звенья, АХЛ, драфт отказов, выкупы, LTIR, ELC, продления, переговоры с агентом, свободные агенты с торгами 32 клубов, обмены с ИИ (встречные предложения, удержание зарплаты, NMC/NTC, дедлайн), сделки ИИ↔ИИ, предложения обменов вам.
- Драфт: реальная лотерея, генерация классов, скаутинг и «туман войны», big board, драфт-рум, мок-драфты, передрафт, МЧМ.
- Мир: владелец и увольнение (с предложениями других клубов), репутация GM, пресс-конференции, лента новостей и соцсетей, оценки сделок и их пересмотр через 3 года, игрок месяца, Матч всех звёзд, награды, история, комната трофеев, выведенные номера, достижения, альбом, итоги сезона.
- Интерфейс: PWA под iPhone, тёмный «ТВ-дизайн» в цветах клуба, карточки с фото и 3D-наклоном, живой матч-центр с картой бросков и сиреной, словарь терминов, ассистент GM.
- Инфраструктура: тесты движка, `calibrate`, `smoke`, GitHub Actions, конфиг Firebase Hosting.

**Упрощено:** офер-шиты и арбитраж заменены автоматическим квалификационным предложением; финансы клуба (билеты, доходы) не моделируются; вмешательство в матч по ходу игры — только повтор.

**Не сделано (следующие шаги):** свой клуб и драфт расширения, мультиплеер с другом, облачные сохранения (Firebase Auth + Firestore), сценарии-челленджи, фэнтези-драфт, таблица АХЛ, «поделиться» картинкой.

**Добавлено 03.10.2026** (подробно — §20): КХЛ как вторая лига мира и режим GM клуба КХЛ, режим «без увольнения», сборные (чемпионат мира каждый май и Олимпиада), карьера игрока (из КХЛ через драфт в НХЛ).

## 0. Коротко

**Что делаем.** Браузерную игру-менеджер в духе Eastside Hockey Manager / Football Manager, но под iPhone. Игрок — генеральный менеджер одного из 32 клубов НХЛ. Старт: октябрь 2026, сезон 2026-27, реальные игроки, контракты, правила и календарь. Цель — выиграть Кубок Стэнли.

**Как играется.** Ты не управляешь хоккеистами на льду. Ты собираешь команду: составы и звенья, обмены, драфт, контракты и переговоры, свободные агенты, бюджет. Матчи симулирует движок, их можно смотреть в «живой» ленте или пропускать.

**Главный принцип: честная математика.** Движок откалиброван по реальной статистике НХЛ. Игра никому не подыгрывает, в том числе тебе, поэтому Кубок даётся тяжело, как и в реальности.

**Платформа.** Сайт, свёрстанный под iPhone в портретной ориентации, который можно установить на домашний экран как приложение (PWA). Хостинг на Firebase Hosting, код в этом репозитории.

### Ожидания по длительности

«Реалистично» значит, что даже сильнейшая команда лиги выигрывает Кубок лишь примерно в каждом пятом сезоне. С 1986 года обладатель Президентского кубка (лучшая команда регулярки) выигрывал Кубок Стэнли лишь примерно в 20% случаев. Поэтому:
- С топ-командой путь к Кубку займёт 1–4 сезона, с аутсайдером — 4–8 (перестройка через драфт).
- Один сезон при быстрой симуляции занимает ориентировочно 30–60 минут игры, в зависимости от того, сколько решений принимаешь.
- Сложность настраивается через ум ИИ-менеджеров и терпение владельца, но не через «кубики» (§6.4).

| **Итого реальных** | **~1 700** | | |
| Мировой пул: КХЛ, SHL, Liiga, NL, DEL, глубина АХЛ, NCAA, CHL | ~2 600 | Реальные (§3.1): API КХЛ, NHL API, заявки сборных | фото КХЛ / силуэт |

**На старте 3 500–4 000 игроков, через 10 сезонов больше 7 000** (с учётом архива ушедших). Выбора хватит на любую стратегию: звёзды через обмены, середнячки на рынке, «алмазы» в Европе и на драфте.

**Настройка «Размер мира»** при создании карьеры:

| Режим | Игроков на старте | Для кого |
|---|---|---|
| Компактный | ~2 000 | Только реальные и минимальный пул, самый быстрый |
| Стандарт (по умолчанию) | ~4 000 | Баланс |
| Огромный | ~8 000 | Максимум выбора; дольше считается межсезонье |

Почему не 20 000: на iPhone ограничены память и хранилище, а тысячи «мусорных» игроков с рейтингом 35 ничего не добавляют в игру. Режим «Огромный» даёт ощущение бесконечного рынка без потери скорости.

## 4. Рейтинги и «цена» игроков

### 4.1 Атрибуты (0–99)

**Полевые игроки:**

| Атрибут | Кратко | Что влияет в движке |
|---|---|---|
| Катание | КАТ | Скорость атаки, возврат в защиту, выносливость |
| Бросок | БРО | Качество бросков → голы |
| Пас / видение | ПАС | Создание моментов → передачи |
| Владение шайбой | ВЛД | Вход в зону, потери |
| Атакующий IQ | АТК | Выбор позиции в атаке, реализация в большинстве |
| Оборонительный IQ | ОБР | Подавление моментов соперника, меньшинство |
| Физика | ФИЗ | Силовая борьба, подборы, удаления соперника |
| Вбрасывания | ВБР | Только для центров |
| Дисциплина | ДИС | Частота удалений |
| Выносливость / здоровье | ЗДР | Риск травм, падение формы к концу матча |

**Вратари:** Позиция, Реакция, Контроль отскоков, Игра клюшкой, Стабильность, Психология (плей-офф и давление).

**Скрытые параметры:** Потенциал (POT), тип кривой развития (ранний / обычный / поздний расцвет), характер (лидерство, профессионализм, лояльность, жадность, желание побеждать), склонность к травмам.

**OVR (общий рейтинг)** — взвешенная сумма атрибутов с весами по позиции (C / LW / RW / D / G).

### 4.2 Как считаем рейтинги из реальной статистики

Скрипт сборки данных (`scripts/build-ratings.ts`) для каждого реального игрока:

1. Берёт 3 последних сезона НХЛ с весами 0,5 / 0,3 / 0,2. Ориентир: 2025-26, 2024-25, 2023-24.
2. Считает темпы на 60 минут: очки и голы в равных составах и в большинстве, броски, хиты, блоки, отборы и потери, % вбрасываний, Корси и on-ice GF/GA (`percentages`, `goalsForAgainst`).
3. **Сжимает к среднему (байесовская регрессия):** при малом числе матчей результат тянется к средней по позиции. Это защищает от случайных вспышек вроде «10 матчей, 12 очков».
4. **Учитывает доверие тренера:** игровое время, ранг по TOI в команде, время в меньшинстве и большинстве. Это сильный сигнал качества, особенно для оборонительных ролей.
5. **Вратари:** регрессированный % отражённых бросков, GSAA (голы, предотвращённые сверх среднего), доля «качественных» матчей, нагрузка.
6. **Проспекты без НХЛ:** статистика в своей лиге × коэффициент перевода (NHLe) плюс поправки на возраст и место на драфте. Ориентиры NHLe: КХЛ ≈ 0,77, SHL ≈ 0,57, NL ≈ 0,46, Liiga ≈ 0,44, АХЛ ≈ 0,39, NCAA ≈ 0,20, OHL/WHL ≈ 0,14, QMJHL ≈ 0,11. При реализации уточнить по свежим исследованиям.
7. **Шкала:** распределение калибруется так, чтобы:
   - 90+ — около 10–15 игроков лиги (суперзвёзды);
   - 85–89 — звёзды, первые звенья;
   - 78–84 — топ-6 нападающих и топ-4 защитников;
   - 70–77 — нижние звенья и третья пара;
   - 60–69 — АХЛ и «вызов из фарма»;
   - ниже 60 — юниоры и глубокий резерв.
8. **Ручные правки** (`data/overrides.json`): для пропустивших сезон из-за травмы, вернувшихся из Европы и прочих исключений.
9. **Проверка:** сила составов по рейтингам должна коррелировать с реальной таблицей 2025-26 (цель r ≥ 0,6) и с предсезонными коэффициентами букмекеров на Кубок 2026-27.

### 4.3 Потенциал и «туман войны»

- Истинный POT скрыт. Игрок видит **оценку скаутов** в виде диапазона, например «POT 78–88».
- Чем больше просмотров и чем сильнее скаутская служба, тем уже диапазон.
- На сложности «Хардкор» скрыты даже точные OVR чужих игроков: видны только отчёты скаутов и статистика.

### 4.4 Три «цены» игрока

| Цена | Что это | Где видно |
|---|---|---|
| **Кэп-хит (AAV)** | Сколько клуб тратит из потолка в год | Карточка, кэп-лист |
| **Рыночная стоимость** | Сколько бы он получил, будь он сейчас свободным агентом | Профиль: «справедливая цена ≈ $X» и «переплата/недоплата» |
| **Обменная ценность** | Сколько он стоит для других GM с учётом возраста, контракта и ситуации | Центр обменов («горячий актив», «неликвид») |

**Модель рыночной стоимости** (стартовая кривая, калибруется на реальных контрактах):

| OVR | Доля потолка | При потолке $104M |
|---|---|---|
| 93+ | 15–20% | $15,6–20,8M |
| 90–92 | 11–15% | $11,5–15,6M |
| 85–89 | 7–11% | $7,3–11,5M |
| 80–84 | 4–7% | $4,2–7,3M |
| 75–79 | 2–4% | $2,1–4,2M |
| 70–74 | 1–2% | $1,0–2,1M |
| < 70 | минимум | $850K–1,0M |

Поправки: возраст (после 30 рынок платит меньше за год, но игрок просит длинный срок), позиция (вратари и правые защитники дороже), статус RFA (около 80–85% от UFA-цены), рост потолка (рынок «инфлирует» вместе с ним).

### 4.5 Откуда реальные контракты

В официальном API контрактов нет. Есть два варианта:

- **A (предпочтительно).** Разовый снимок кэп-данных с публичного источника. Проверено: CapWages отдаёт на страницах клубов кэп-хит, NMC/NTC, RFA/UFA и сроки. **Сначала проверить условия использования**, указать источник в игре и обновлять снимок вручную скриптом.
- **B (запасной).** Модель из §4.4 по OVR, возрасту и статусу плюс ручная правка крупных контрактов (около 150–200 звёзд) в `data/contracts-overrides.json`.

В игре подпись: «Контракты по данным на 01.10.2026».

## 6. Матчевый движок и честность

### 6.1 Модель матча

Матч разбит на сегменты (около 20 секунд, это примерно длина смены). В каждом сегменте:

1. Определяется, кто на льду: звенья по схеме тренера, усталость, удаления (5×5, 5×4, 4×4, 3×3, пустые ворота).
2. Интенсивность моментов каждой команды:
   `λ_атака = базовый_темп × f(атака звена − оборона соперника) × множитель_состава`.
3. Моменты становятся бросками с качеством (xG); гол забивается с вероятностью `p = xG × f(бросок) / g(вратарь)`.
4. Удаления — из дисциплины и физики игроков (около 3 большинств на команду за матч).
5. Автор гола и передачи распределяются по вкладу игроков на льду (бросок, пас, роль).
6. Поправки: домашний лёд, усталость, игры в два дня подряд, форма (небольшая автокорреляция, «серии»).
7. **Овертайм:** в регулярке 3×3, 5 минут, затем буллиты (отдельная модель «стрелок против вратаря»). **В плей-офф** — периоды по 20 минут 5×5 до гола.
8. В конце матча проигрывающая команда снимает вратаря по реальной логике тренеров.
9. На выходе: счёт, броски, протокол, три звезды, оценки игроков, травмы, текстовая лента событий для «живого» просмотра.

### 6.2 Калибровка (критерий готовности движка)

Автотест симулирует **1 000 сезонов** и проверяет, что метрики попали в коридор:

| Метрика | Реальность (2025-26) | Коридор в симуляции |
|---|---|---|
| Голов на команду за матч | 3,08 | 2,95–3,20 |
| Доля матчей с ОТ/буллитами | 24,8% | 21–28% |
| PP% | 21,1% | 19–23% |
| Средний % отражённых бросков | 0,896 | 0,890–0,905 |
| Побед хозяев | 52,2% | 51–56% |
| Очки лучшей команды (84 матча) | 121 за 82 матча | 112–130 |
| Очки худшей команды | 58 за 82 матча | 52–72 |
| Лидер бомбардиров | 138 | 110–145 |
| Лидер регулярки берёт Кубок | ≈ 20% исторически | 12–25% |
| Фаворит серии плей-офф побеждает | ≈ 55–65% | 55–68% |

Если хоть одна метрика вне коридора, движок считается сломанным, а сборка падает.

### 6.3 Прозрачность шансов

Игрок видит те же вероятности, что и движок, рассчитанные методом Монте-Карло:
- перед матчем: «Шанс победы 57%»;
- перед серией: «Шанс пройти 64%»;
- прогноз сезона: «Плей-офф 71% · Кубок 6,2%», обновляется после каждой недели;
- при сделке: «Как изменится шанс на Кубок: +1,8 п.п.».

### 6.4 Жёсткие правила честности

1. **В движке нет понятия «команда игрока».** Функции симуляции не получают флаг `isUser`, и это проверяется тестом.
2. Вся случайность идёт через **детерминированный генератор с зерном**: одно зерно и одни решения дают один результат.
3. **Никакого rubber-banding:** нет «камбэк-механик», невидимых бонусов отстающим и «драмы ради драмы».
4. **Сложность меняет только людей, а не кубики:** насколько жадны и умны ИИ-менеджеры, терпение владельца, точность скаутов. Шансы в матчах одинаковы на всех уровнях.

| Сложность | ИИ в обменах | Владелец | Скауты |
|---|---|---|---|
| Новичок | Мягкий, прощает переплаты | Терпелив | Точнее |
| Реализм (по умолчанию) | Как настоящие GM | Как в жизни | Обычные |
| Хардкор | Жёсткий, помнит обиды | Нетерпелив | Только диапазоны, OVR скрыт |

## 7. Обмены

### 7.1 Модель ценности

**Игрок:**
```
V_игрок = Σ_{год t в горизонте}  δ^t · W(OVR_t) · K_позиции  +  Сурплюс_контракта
```
- `OVR_t` — прогноз рейтинга на год t по кривой старения (§10).
- `W(OVR)` — выпуклая функция: звезда стоит непропорционально больше середнячка.
- `δ` зависит от стратегии клуба: контендеру важен «сейчас» (δ ≈ 0,6), перестройке — «потом» (δ ≈ 0,95).
- Сурплюс = Σ (рыночная стоимость − кэп-хит) по годам контракта. Дешёвый хороший игрок стоит дорого, дорогой ветеран может иметь отрицательную ценность.

**Пик драфта:**
```
V_пик(n) = A · e^(−k·(n−1)) + B
```
`n` — ожидаемый номер пика. Будущие пики оцениваются через прогноз места клуба: пик слабой команды ценнее. Каждый год до драфта даёт дисконт.

**Проспект:** функция от диапазона POT, возраста и уверенности скаутов.

### 7.2 Как думает ИИ-менеджер

- **Стратегия клуба:** контендер, «на пузыре» или перестройка. Определяется таблицей, возрастом состава и кэп-ситуацией, может меняться по ходу сезона.
- **Потребности:** дыры по позициям («нужен правый защитник»), кэп-спейс, лимит контрактов.
- **Порог согласия:** сделка должна увеличить ценность для ИИ хотя бы на маржу (зависит от сложности и отношений). Около порога решение вероятностное, и ИИ отвечает **встречным предложением** («добавьте пик 3-го раунда»).
- **Память и отношения:** если «обуть» GM, следующие сделки с ним будут дороже. Честные сделки улучшают отношения.

### 7.3 Правила (как в НХЛ)

- Удержание зарплаты до 50%, не больше 3 контрактов с удержанием у клуба одновременно.
- NMC — обмен только с согласия игрока; NTC — список запрещённых клубов, и игрок может отказаться.
- После обмена обе стороны должны укладываться в потолок. Лимит 50 контрактов обмены не блокирует (правило игры, отступление от НХЛ): после сделки у клуба может стать больше 50 контрактов, но новых свободных агентов он подписать не сможет, пока не опустится ниже лимита.
- Дедлайн обменов: после него обмены закрыты до конца плей-офф.
- Пики можно обменивать на 3 драфта вперёд.

### 7.4 Защита от эксплойтов

- **Количество не заменяет качество:** пакет оценивается не простой суммой, а «p-нормой» `(Σ V_i^p)^(1/p)` с p ≈ 1,5, плюс штраф за занятые места в составе. Четыре середнячка ≠ звезда.
- Нет «перепродажи по кругу»: ИИ не берёт игрока, которого только что отдал, и видит повторяющиеся схемы.
- ИИ проверяет здоровье игрока (травмированный дешевеет) и не берёт контракты, которые ломают ему потолок.

### 7.5 Живая лига

- ИИ-клубы меняются **между собой**, ориентир — несколько десятков сделок за сезон, пик перед дедлайном.
- ИИ сам присылает предложения тебе, а в ленте появляются слухи («Бостон ищет центра второго звена»).
- Игроки могут попросить обмен (мало игрового времени, перестройка клуба, конфликт).

### 7.6 Экран обмена (iPhone)

Две «корзины» друг под другом: **Отдаёшь ↕ Получаешь**. Внизу шкала реакции ИИ: «холодно → тепло → согласен». Кнопки «Что вы хотите за него?» (ИИ сам собирает запрос) и «Предложить». Цифры ценности скрыты, видна только реакция.

### 7.7 Доступны для обмена и советник (Рынок → «Доступны»)

Движок `src/engine/tradeAdvice.ts` только читает лигу: не меняет состояние и не тянет случайные числа (проверяет тест).

- **Кто доступен.** Игроки, которых ИИ-клубы сами готовы отдать, по тем же правилам, по которым они продают друг другу: ветераны перестраивающихся клубов (27+) и середняков (30+), лишние в составе и в фарме, истекающие контракты у не-претендентов, переплаченные контракты, клубы над потолком, игроки, попросившие обмен. Лидеры клуба (топ по ценности для своего клуба и по рейтингу, у претендента 6, у середняка 5, у перестройки 4) и молодые таланты не продаются. Исключение — просьба об обмене, а у перестройки ещё и возраст 30+. NMC без просьбы об обмене — тоже не продаются.
- **Что усилить.** Звенья лучшего состава сравниваются со средним клубом лиги слот за слотом: 1–4-й центр, крайние каждого звена, пары защиты, основной вратарь. В потребности попадает разрыв от 2 пунктов; вес — доля слота в силе команды. Дополнительно: нехватка игроков по позициям, атака топ-6 для стиля «Атака» и оборона топ-4 для «Обороны», а после 15 матчей — большинство и меньшинство на 3+ п.п. хуже лиги.
- **Стиль команды.** Задаётся тактикой, при «Балансе» — стилем главного тренера. Соответствие стилю считается по профилю «атака − оборона» относительно медианного игрока той же позиции в лиге.
- **Советы.** Каждого доступного игрока ставим в лучший состав (тот же `buildLines`). Показываем прирост силы команды и примерные очки в таблице по той же модели, что и прогнозы (`winProb`): кого он вытеснит, какие потребности закроет, подходит ли стилю, влезает ли под потолок, цену (квантиль ценности для его клуба). Порядок: реальный прирост, стиль и закрытые потребности его уточняют.
- **Чем расплатиться.** Ваши игроки, без которых лучший состав почти не слабеет, а другие клубы их ценят.
- Кнопка «Узнать цену» открывает обмен с этим игроком и сразу спрашивает, что клуб хочет взамен.

## 8. Контракты и переговоры

### 8.1 Правила (§2)

Потолок, минимум и максимум зарплаты, сроки 7/6 лет, ELC, RFA/UFA (UFA с 27 лет или после 7 сезонов в лиге), квалификационные предложения, арбитраж, офер-шиты с компенсацией пиками (по таблице, индексируемой к средней зарплате), выкупы, LTIR.

**Выкуп по реальным правилам:** 2/3 оставшейся суммы для игроков 26+ и 1/3 для младше 26; нагрузка на потолок растягивается на удвоенный оставшийся срок.

**Драфт отказов:** игрок без иммунитета, отправляемый в АХЛ, проходит waivers. Другие клубы могут забрать его в порядке обратной таблицы.

### 8.2 Характер игрока и агента

| Черта | Что меняет |
|---|---|
| Жадность | Запрос выше рынка, сложнее уступает |
| Лояльность | Скидка своему клубу, охотнее продлевает |
| Желание побеждать | Важнее, контендер ли клуб; готов взять меньше ради Кубка |
| Роль | Хочет гарантированное место в топ-6 / топ-4 / как основной вратарь |
| Безопасность | Предпочитает длинный срок даже ценой меньшей суммы |
| Тип агента | «Жёсткий» (блефует о других предложениях), «Партнёр» (договороспособен), «Рекордсмен» (ему нужна громкая сумма) |

### 8.3 Механика переговоров

- Предложение состоит из суммы AAV, срока, пунктов NMC/NTC и (упрощённо) доли бонусов за подписание.
- У игрока есть **запрос A** и скрытый **минимум M**:
  - если предложение ≥ A, он соглашается сразу;
  - если между M и A, соглашается с вероятностью, растущей к A, иначе даёт встречное;
  - если ниже M, это «лоубол»: шкала **терпения** падает пропорционально разнице. При нуле агент прерывает переговоры, а при продлении игрок уходит на рынок.
- Срок и сумма — компромисс: молодые звёзды хотят либо короткий «бридж», либо максимум; ветераны хотят срок.
- Агент может блефовать («у нас есть предложение на $9M»). Хорошие скауты и отношения подсказывают, правда ли это.
- Подсказки интерфейса: «похожие контракты» (3–5 сопоставимых игроков) и «вилка» рыночной стоимости.

### 8.4 Свободные агенты (1 июля)

- Рынок живёт несколько игровых дней. Все 32 клуба (31 ИИ + ты) делают предложения.
- Игрок выбирает по функции полезности:
  `U = деньги(AAV, срок) + w_победа·сила_клуба + w_роль·ожидаемое_время + w_лояльность + w_город + шум`.
- Звёзды решают быстрее, рынок середнячков тянется дольше.
- Можно «подождать», чтобы цена упала, рискуя, что игрока заберут.

### 8.5 RFA и офер-шиты

- Квалификационное предложение сохраняет права. Без него игрок становится UFA.
- Арбитраж (упрощённо): арбитр называет сумму на основе сопоставимых контрактов, взвешивая требования сторон.
- Офер-шит игроку другого клуба: тот может уравнять или отпустить игрока за компенсацию пиками.

## 9. Драфт

### 9.1 Лотерея

Реальная формула из §2. Отдельный экран: шары, «вскрытие конвертов» в обратном порядке, драматичная пауза перед первым номером.

### 9.2 Генерация драфт-класса

- Около 350 проспектов в классе: на 224 пика с запасом, недрафтованные становятся свободными агентами.
- Страны (ориентир): Канада ~40%, США ~25%, Швеция ~9%, Финляндия ~6%, Россия ~6%, Чехия ~5%, остальные ~9%.
- Лиги: OHL, WHL, QMJHL, USHL, NCAA, SHL/J20, Liiga/U20, МХЛ/КХЛ, NL и др.
- Позиции: ~60% нападающих, ~30% защитников, ~10% вратарей.
- Таланты: «поколенческий» талант в среднем раз в 5–8 лет; сила классов отличается (бывают сильные и слабые годы).

### 9.3 Скаутинг

- Бюджет скаутинга и скауты с регионами (Северная Америка, Европа, Россия) и разной точностью.
- Публичный рейтинг лиги (аналог Central Scouting) общий для всех и неточный.
- Свой «большой список» (big board): перетаскиваешь проспектов; ИИ-клубы ведут свои.
- Комбайн: физические тесты и интервью (характер).

### 9.4 Драфт-день

- Экран «на часах» с таймером, твой big board, лучшие оставшиеся по позициям.
- ИИ-клубы выбирают по своим доскам с характером (лучший доступный или по нужде, любят габариты, любят европейцев) и шумом.
- Обмены пиками прямо во время драфта («подняться на 5 мест»).
- Анимация объявления пика: свитер клуба, имя, позиция, «оценка экспертов».

### 9.5 После драфта

ELC (до $1,0M для класса 2026, далее минимум + $175K), отправка в юниоры, АХЛ или Европу. Права на неподписанных истекают в 22 года по новому CBA.

## 10. Развитие, старение, травмы, мораль

**Кривые старения (ориентиры, со случайностью):**

| Возраст | Нападающие | Защитники | Вратари |
|---|---|---|---|
| 18–21 | Быстрый рост (+3…+8/год) | Рост (+2…+6) | Медленный рост |
| 22–25 | Рост (+1…+4) | Рост (+1…+4) | Рост (+2…+4) |
| 26–29 | Пик (±1) | Пик (±1) | Рост / пик |
| 30–32 | Спад (−1…−3) | Спад (−1…−2) | Пик / лёгкий спад |
| 33–35 | Спад (−2…−5) | Спад (−2…−4) | Спад (−1…−4) |
| 36+ | Резкий спад, завершение карьеры | То же | То же |

- Скорость развития зависит от POT, игрового времени (АХЛ лучше, чем скамейка в НХЛ), профессионализма и уровня тренерского штаба.
- Есть «поздние расцветы» и «бусты»: потенциал — диапазон, а не гарантия.
- **Травмы:** легкие (1–7 дней, большинство), средние (2–6 недель), тяжёлые (до конца сезона). Частота калибруется на реальные «потерянные человеко-матчи»; склонность к травмам — скрытый параметр. Есть IR/LTIR по правилам.
- **Мораль и химия:** химия звена растёт, пока звено играет вместе; лидеры поднимают раздевалку; обмен капитана временно снижает мораль; игрок без игрового времени недоволен и может попросить обмен.
- **Завершение карьеры:** вероятность по возрасту, OVR и наличию контракта.

## 11. Карьера GM, владелец, новости

- **Владелец клуба** ставит цель на сезон по силе команды: «попасть в плей-офф», «пройти раунд», «Кубок», «развить молодёжь». Шкала доверия меняется по результатам и решениям (бюджет, громкие сделки).
- **Увольнение:** доверие на нуле — тебя увольняют. Дальше либо конец карьеры, либо через какое-то время предложения от других клубов (карьера продолжается в новом городе).
- **Выбор команды на старте:** карточки 32 клубов со звёздами сложности, кэп-спейсом, шансом на Кубок и описанием («Окно открыто — 2 сезона», «Полная перестройка»).
- **Новости и входящие:** слухи, травмы, просьбы игроков, предложения обменов, итоги дня. Инсайдеры вымышленные.
- **Награды:** Hart, Vezina, Norris, Calder, Selke, Art Ross, Rocket Richard, Conn Smythe и «GM года» (твоя личная цель).
- **История:** чемпионы по годам, рекорды, комната трофеев, зал славы, твоя карьерная статистика. Карьерная статистика реальных игроков стартует с их настоящих цифр.

## 12. Дизайн: «дорого»

### 12.1 Концепция

**«Ночная арена / ТВ-трансляция».** Тёмный фон, лёд, свет прожекторов, графика как в эфире: табло, плашки и «лоуэр-тёрды».

- **Палитра (токены):** фон `#07090F`, поверхности `#0E131D` и `#151C29`, лёд-акцент `#7FD3FF`, золото трофеев `#E8C26A`, успех `#3DDC97`, опасность `#FF5A5F`. **Акцент интерфейса = основной цвет выбранного клуба**: вся игра «перекрашивается» в цвета твоей команды.
- **Материалы:** матовое стекло (`backdrop-filter`) на плашках, тонкие светлые границы 1px, мягкое свечение у ключевых чисел, лёгкое «зерно».
- **Шрифты (с кириллицей):** заголовки и числа — Oswald (сжатый, «спортивный»); текст — Inter с моноширинными цифрами, чтобы колонки статистики не прыгали.
- **Движение:** пружинные переходы между экранами, плавное «перетекание» карточки игрока из списка в профиль, скелетоны вместо спиннеров. Всё на `transform`/`opacity` для 60 fps; учитывается системная настройка «Уменьшить движение».
- **Звук (опционально, по умолчанию выкл.):** сирена гола, шум трибун на ключевых моментах.

## 13. iPhone: управление и удобство

**Устройства:** от iPhone SE (ширина 375 pt) до Pro Max (440 pt). Основной режим — **портрет**. В ландшафте раскладка не ломается (колонка по центру), но специально под него не проектируем.

**Размеры (нормы Apple HIG):**

| Элемент | Размер |
|---|---|
| Основная кнопка (CTA) | высота 50 pt, ширина по контенту или на всю ширину с полями 16 pt |
| Вторичная кнопка | высота 44 pt |
| Иконка-кнопка | зона нажатия ≥ 44×44 pt (иконка 22–24 pt) |
| Строка списка игроков | 60–64 pt |
| Таб-бар | 49 pt + нижний safe area |
| Отступ между нажимаемыми элементами | ≥ 8 pt |
| Боковые поля экрана | 16 pt |
| Текст | основной 16–17, подписи 13, минимум 11 |
| Поля ввода | шрифт ≥ 16 px, иначе Safari зумит страницу |

**Эргономика:**
- Главные действия внизу, в зоне большого пальца. Сверху только информация.
- **Bottom sheets** (выезжающие снизу панели) вместо модальных окон по центру: действия с игроком, фильтры, подтверждения.
- **Свайп по строке игрока:** «Обмен», «Продлить», «В АХЛ». **Долгое нажатие:** быстрый просмотр карточки.
- Звенья на телефоне ставятся по схеме «тап по позиции → выбор из списка», без перетаскивания, которое на маленьком экране неудобно.
- Фильтры — сегментированные переключатели и «чипсы» (позиция, возраст, OVR, контракт).
- Pull-to-refresh и «резиновый» скролл в оболочке приложения отключены.

**Техника iOS:**
- `viewport-fit=cover`, отступы через `env(safe-area-inset-*)` (Dynamic Island, полоска «домой»), высота через `100dvh`.
- **PWA:** манифест, `apple-touch-icon`, splash-экраны, `display: standalone`, `apple-mobile-web-app-status-bar-style: black-translucent`. После «На экран Домой» открывается как приложение, без адресной строки, и работает офлайн.
- В Safari нет виброотклика (Vibration API) — компенсируем микроанимациями.
- **Сохранения:** Safari может стереть данные сайта, который не открывали 7 дней. Защита: установка на домашний экран, `navigator.storage.persist()`, экспорт и импорт файла сохранения через «Поделиться» и (позже) облачные сохранения Firebase.

**Скорость:**
- Симуляция в Web Worker: интерфейс не подвисает, пока считается неделя.
- Виртуализированные списки: 4 000 игроков листаются плавно.
- Ленивая загрузка фото; данные мира грузятся один раз и кэшируются.
- Ориентир: сезон целиком симулируется за 5–15 секунд на iPhone 12+.

**Тестирование:** Playwright с профилями iPhone SE, iPhone 15 и 16 Pro Max (WebKit) плюс реальный iPhone по превью-ссылке Firebase для каждого PR.

### 14.3 Модель данных (основное)

- **Player:** id (NHL id или сгенерированный), имя, дата рождения, страна, позиция, хват, рост/вес, фото, атрибуты, скрытые параметры, статистика по сезонам, статус (НХЛ / АХЛ / юниоры / Европа / FA / завершил), права (клуб), травма, мораль.
- **Contract:** AAV, годы (по сезонам), тип (ELC / стандарт / 35+), RFA/UFA по окончании, NMC/NTC, удержание, выкуп.
- **Team:** клуб, цвета, логотип, дивизион, стратегия ИИ, big board, скауты, бюджет, владелец, звенья и пары.
- **DraftPick:** год, раунд, исходный и текущий владелец, условия.
- **LeagueState:** дата, фаза, календарь, результаты, таблица, сетка, история, лента новостей, зерно RNG.

Размер сохранения: около 4 000 игроков × 1–2 КБ ≈ 4–8 МБ. Для IndexedDB это нормально. Старые сезоны сжимаются: детальные протоколы удаляются, итоговая статистика остаётся.

2. `fetch-contracts.ts`: вариант A или B из §4.5.
3. `build-ratings.ts`: §4.2.
4. `generate-world.ts`: мировой пул, детерминированно по зерну.
5. `validate-data.ts`: у каждого клуба ≤ 50 контрактов, сумма кэп-хитов близка к реальной, распределение OVR в коридорах, у всех есть позиция и возраст.
6. Результат: `public/data/world-2026-10.json` (сжатый около 0,5–1 МБ).

**Обновление базы** (например, к следующему сезону) — повторный запуск скриптов и новый снимок. Игра в рантайме API НХЛ не дёргает, только фото с CDN.

### 14.5 Firebase

- `firebase.json`: `public: dist`, SPA-rewrite на `/index.html`; кэш `immutable` для хэшированных файлов и `no-cache` для `index.html` и сервис-воркера.
- GitHub Actions:
  - на каждый PR — сборка, тесты и **превью-ссылка** Firebase (удобно открыть на iPhone и проверить);
  - на merge в `main` — деплой в live.
- **Что нужно от тебя:**
  1. Создать проект в Firebase Console и включить Hosting.
  2. Выполнить `firebase init hosting:github` (сам положит секрет сервис-аккаунта в GitHub) или прислать ID проекта, а секрет добавить вручную.
  3. Решить, нужен ли свой домен.

## 20. КХЛ, карьера игрока, сборные (добавлено 03.10.2026)

### 20.1 Режимы карьеры

| Режим | Кем играет пользователь | Что управляет ИИ |
|---|---|---|
| GM НХЛ | генеральный менеджер одного из 32 клубов | все остальные клубы НХЛ и КХЛ |
| GM КХЛ | генеральный менеджер одного из 22 клубов КХЛ | все остальные клубы |
| Карьера игрока | один созданный игрок (18 лет, клуб КХЛ) | все клубы, включая клуб игрока |

Опции новой карьеры: «Без увольнения» (`settings.noFiring`: доверие владельца считается и влияет на сообщения, но увольнения нет), «Россия и Беларусь на турнирах IIHF» (`settings.intlRussia`, по умолчанию выключено — как в реальности), сборная для тренера (необязательно).

### 20.2 КХЛ: данные и правила (проверено 03.10.2026)

- 22 клуба сезона 2026-27, по 11 в Западной и Восточной конференциях (khl.ru, sport-express.net, ru.wikipedia.org). Действующий чемпион — «Локомотив» (Кубок Гагарина 2026, 4–2 в финале с «Ак Барсом»).
- 68 матчей: дома и в гостях со всеми (42), ещё по два матча с соперниками по конференции (20) и 6 матчей «добора». Регулярка 5 сентября — 20 марта, плей-офф 23 марта — 23 мая. Первая регулярка в игре стартует вместе с карьерой (29.09.2026) и тоже заканчивается 20 марта.
- Плей-офф 2026-27: по 8 команд из конференций, первый раунд внутри конференций (1–8, 2–7, 3–6, 4–5), дальше — перепосев по общей таблице регулярки на каждой стадии, серии до 4 побед, 2-2-1-1-1.
- Потолок зарплат ₽950 млн (2026-27) и ₽1 млрд (2027-28), нижняя граница ₽525 млн / ₽600 млн; дальше — ориентир +3% в год. Лучшие зарплаты лиги ₽75–100 млн, фонд лиги ≈ ₽13,8 млрд (≈ ₽630 млн на клуб) — по ним откалибрована кривая зарплат.
- Лимит легионеров: в заявке на матч не больше 5 иностранцев. Упрощение: российский клуб не может иметь больше 5 иностранцев с контрактом; у «Динамо» Минск, «Барыса» и «Шанхайских Драконов» лимита нет; россияне, белорусы и казахстанцы (ЕАЭС) легионерами не считаются.
- Дедлайн обменов — 25 января. Драфта отказов и удержания зарплаты при обменах нет. Обмены только внутри лиги.
- Деньги хранятся в долларах; суммы КХЛ задаются в рублях и пересчитываются по фиксированному курсу-ориентиру (85 ₽/$). В интерфейсе клубов КХЛ всё показывается в рублях.
- Составы клубов КХЛ реальные (API приложения КХЛ, 707 игроков), сила клубов складывается из игроков. Каждое лето клубы получают 2–3 воспитанников академии (вымышленные — это будущие игроки).

### 20.3 КХЛ: калибровка

Тот же матчевый движок. КХЛ — более плотная лига: параметр стиля лиги (`LEAGUE_STYLE`: объём бросков ×0,95, реализация ×0,9) одинаков для обеих команд любого матча КХЛ и не знает о пользователе. Коридоры в `scripts/calibrate.ts` (реальность 2025-26): голов на команду за матч 2,6–2,95 (≈2,75), овертаймы 20–30%, победы хозяев 50–57%, % отражённых 0,895–0,915, лучшая команда 92–112 очков (у «Металлурга» 105), худшая 45–66, лучший бомбардир 68–95 (89).

### 20.4 Связь лиг

- Свободные агенты 1 июля — общий рынок. Игрок сравнивает деньги после налогов (налог в России 13–15% против ~40–50% в Северной Америке — коэффициент 1,4 к зарплате КХЛ), лигу (мечта об НХЛ; россиянам, белорусам и казахам интересно играть дома), роль и шансы клуба. Явные игроки НХЛ рассматривают КХЛ только после первой недели рынка.
- Драфт НХЛ: молодые игроки клубов КХЛ попадают в пул. Клуб НХЛ получает права (`Player.rights`), игрок остаётся в КХЛ до конца контракта. Когда контракт истекает, клуб НХЛ может подписать его (ИИ — если игрок готов; пользователь — во вкладке «Состав → Права»). Права действуют до 22 лет.

### 20.5 Сборные

- Чемпионат мира — каждый май. 2027: Германия (Дюссельдорф, Мангейм), 14–30 мая, группы A: SUI FIN SWE DEU LVA AUT SVN UKR, B: CAN USA CZE SVK DNK NOR KAZ HUN (действующий чемпион — Финляндия). 16 команд, группы по 8, очки IIHF 3-2-1-0, четвертьфиналы A1–B4, A2–B3, B1–A4, B2–A3, полуфиналы с перепосевом, матчи за медали; последние команды групп вылетают, две сборные первого дивизиона поднимаются (шанс выше у сильных составов).
- Олимпиада — каждые 4 года с 2030 (Французские Альпы, игроки НХЛ участвуют): 12 команд, три группы по 4, квалификация 5–12, четвертьфиналы. НХЛ и КХЛ уходят на паузу, Матча всех звёзд в олимпийский сезон нет.
- Составы: лучшие доступные игроки страны из всех лиг (рейтинг и форма). Игроки клубов, которые ещё в плей-офф, на ЧМ не едут; звёзды НХЛ нередко отказываются от ЧМ (детерминированно по игроку и году), от Олимпиады — нет. Малым хоккейным странам добавляются игроки внутренних лиг, чтобы была полная заявка.
- Россия и Беларусь отстранены IIHF с 2022 года (на ЧМ-2027 их нет). Если включить настройку, они заменяют две слабейшие по рейтингу сборные поля.
- GM может возглавить сборную и менять предложенный штабом состав до старта турнира. Статистика сборных хранится отдельно (`2027wc`, `2030og`), медали — в профиле игрока.

### 20.6 Карьера игрока

- Создание: имя, амплуа, страна, клуб КХЛ. Возраст 18, рейтинг/потолок по сложности: новичок 72/90, реализм 70/87, хардкор 68/84. Первый контракт — 2 сезона по уровню игры, а не потенциала.
- Игрок развивается по общим правилам (летний лагерь, фокус тренировок, игровое время). Звенья ставит ИИ-тренер по рейтингу; оставшегося без игр отправляют в фарм (ВХЛ/АХЛ), где статистика — оценка по уровню (фарм-лиги не симулируются полностью).
- Контракты приходят через агента: в мае последнего сезона контракта и всё время, пока игрок без клуба. Права драфта НХЛ закрывают другие клубы НХЛ; ограниченно свободного агента НХЛ может переподписать только его клуб. Договорённость весной вступает в силу 1 июля. ИИ никогда не подписывает и не меняет игрока пользователя без его решения (кроме обмена по его же просьбе).
- Действия: фокус тренировок, разговор с тренером о времени на льду (честный ответ, сколько не хватает до следующего звена), просьба об обмене, завершение карьеры. Свои достижения (дебют, драфт, НХЛ, сборная, Кубок Гагарина/Стэнли).
